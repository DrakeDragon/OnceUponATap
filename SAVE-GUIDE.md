# Save backup and upgrade guide — v42

1. Before replacing game files, open More > Backup save > Copy. Paste the code into a text file outside the browser. Keep your previous playable ZIP and export.
2. Replace files at the SAME address, browser and local port. Open v42. Existing100-character towns keep their current save structure. Original20-realm towns migrate only after an original-town backup is written. Full storage or invalid data stops loading with a protected-town message instead of creating a fresh replacement.
3. More > 100-character campaign > Review shows archived removed residents/buildings. They remain historical earned progress; existing archived jobs keep deadlines and settle once. No new archived jobs run.
4. Copy original v18 save exports the complete pre-cut town if present. More > Backup save > Copy exports the current town INCLUDING its archive. Keep these exports separately.
5. To roll back, serve the matching previous game and import its corresponding export. Later progress does not merge into that rollback. To move browser/device/address, import the current export there.
6. Do not clear site storage, use Reset or overwrite your only external code during upgrade checks. Browser backup keys share the same storage and do not protect against clearing browser data.

Archived collection pays saved base coins/XP including original friendship/charm bonuses and updates archived friendship/discoveries/task counts once. It does not run random twists, combos, wishes, treasure chests or discovery bonus rolls. Retained timers/rewards continue normally. Automated compatibility checks pass; actual player-town device upgrades remain an acceptance gate.
